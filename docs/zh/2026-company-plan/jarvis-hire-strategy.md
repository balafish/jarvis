## 里程碑 01：成果導向收費

### 核心邏輯
傳統人力銀行以「刊登費」收費，不論是否成功錄用。Jarvis Hire 改為「成功錄用才收費」，將平台利益與企業結果完全對齊，大幅降低客戶試用門檻，同時建立高達 15–20% 的成功傭金收入模型。

### 越南市場適配性
- 越南本地企業（B端）採購保守，前期刊登費抗拒度高——成果導向直接消除此障礙
- 越南招募失敗率高（試用期留存普遍低於 60%），企業對「有效媒合」需求極強
- 台商在越企業對績效導向採購有文化認同，導入阻力最低

### 收費模式設計

| 層次 | 說明 |
|------|------|
| 基礎層 | 免費刊登職缺（引流） |
| 進階層 | AI 精準媒合 + 候選人短名單，月訂閱制 |
| 成果層 | 錄用後 30 天到職確認，收取首月薪資 15–20% 作為成功費 |
| 保障條款 | 到職 90 天內離職，免費補缺一次（強化信任） |

### 護城河效果
成果導向倒逼平台提升媒合品質 → 沉澱高品質數據 → AI 媒合準確率提升 → 成功率更高 → 定價能力更強。這是一個自我強化的競爭飛輪。

## 里程碑 02：RPO 專業服務化

### 核心邏輯
RPO（招募流程外包）是將企業整個招募作業委託給第三方專業夥伴——從職缺規劃、人才搜尋、篩選、面試協調到 Offer。Jarvis Hire 以平台流量 + AI 媒合引擎 + 越南在地顧問團隊，三位一體承接中型以上企業的招募委託，從廣告平台晉升為「戰略人才夥伴」。

### 越南市場痛點
- 越南外資企業（尤其台商）普遍缺乏在地 HR 資源，自主招募耗時且失敗率高
- 平均每個非主管職缺需耗費 53 天以上才能錄用，企業損耗極大
- 語言障礙（中越文）使得招募流程摩擦成本高，本地平台難以解決

### 服務層次設計

| 方案 | 說明 | 計費方式 |
|------|------|---------|
| Project RPO | 單一專案委託，適合新廠開幕或季節性大量招募 | 按人頭計費 |
| Modular RPO | 委託特定招募階段（如：篩選+面試協調） | 月費制 |
| Full RPO | 整體招募流程外包，嵌入企業 HR 作業 | 年約制（最高黏著度） |

### 台商專屬優勢
Jarvis Hire 提供中越雙語顧問，熟悉台商企業文化與薪酬結構，能精準對標越南本地人才市場，這是純本地平台或純台灣獵才公司均無法複製的組合優勢。

## 里程碑 03：雇主評價生態系統

### 核心邏輯
越南目前缺乏可信賴的雇主評價平台——求職者主要靠口耳相傳或 Facebook 非正式社群。Jarvis Hire 建立經身份驗證的雇主評分系統（曾應徵或在職者才可評論），形成台灣 104 和 Glassdoor 都未能深耕的越南市場空白，進而創造信任護城河。

### 為何從零建立不是弱點
- 越南市場本身沒有強勢競爭者——空白市場先入者優勢顯著
- 與 RPO / 成果導向服務天然聯動：錄用後系統自動邀請雙方評價，快速冷啟動
- 每一筆評價都是數據資產，累積後形成越南最大雇主洞察資料庫

### 商業化路徑

| 模式 | 說明 |
|------|------|
| 免費開放 | 求職者可查看雇主評分（流量驅動） |
| 企業訂閱 | 雇主可管理回覆、查看詳細分析報告（月費制） |
| 雇主品牌廣告 | 高評分企業付費強化曝光，吸引被動求職者（CPC / CPM） |
| 薪資透明化報告 | 產業薪資數據報告向 HR / 媒體販售（B2B 數據產品） |

### 風險控管
採取三層驗證機制：手機驗證 + 曾應徵記錄比對 + AI 異常偵測，並建立明確的申訴流程，確保生態系統公信力。

## 里程碑 04：東南亞台商人才供應鏈

### 核心邏輯
台灣企業在越南、泰國、印尼等地擁有大量製造與服務業據點，長期面臨跨境人才管理三大痛點：台幹外派（薪資結構、勞動法規）、在地幹部培育（語言、文化落差）、回台任用（職涯銜接）。Jarvis Hire 以雙語平台為基礎，打造台商在越的「人才一站式服務窗口」。

### 三大服務場景

| 場景 | 說明 |
|------|------|
| 台幹外派媒合 | 協助台灣總部尋找願意外派越南的中高階台籍人才，提供薪酬對標 + 簽約支援 |
| 在地幹部招募 | 為台商在越工廠/辦公室招募越籍幹部，強調中越文雙語能力與企業文化適配 |
| 回台任用橋接 | 協助在越培育成熟的越籍幹部對接台灣總部職缺，實現人才迴流價值 |

### 護城河：為何難以複製

| 競爭者 | 缺口 |
|--------|------|
| 純越南本地平台 | 缺乏台商企業文化理解與中文服務能力 |
| 台灣傳統獵才公司 | 無越南在地資料庫、無當地法規熟悉度 |
| LinkedIn 等國際平台 | 語言與文化脈絡不足，無法深入服務台商需求 |
| Jarvis Hire | 三者皆具，獨一無二的組合壁壘 |

### 擴張路徑
越南（灘頭堡）→ 泰國、印尼台商聚集區 → 東南亞台商人力資源聯盟 → 對接台灣政府南向政策合作資源
