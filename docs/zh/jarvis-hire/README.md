# Jarvis Hire（越南人力市場）

成果導向人力媒合引擎，鎖定越南市場中文人才招募需求。

## 定位

**不是人力銀行**，而是**將招募需求轉換為已驗證營收的執行系統**。

主要服務台商、中資、港資在越南設廠／營運的中文人才招募需求。

## Phase 1 速覽

| 項目 | 內容 |
|------|------|
| 期程 | 0–6 個月 |
| 主要目標 | 建立可重複的「招募 → 收款」執行系統 |
| 核心市場 | 越南（HCMC、平陽、同奈工業區）|
| 目標客戶 | 50–500 人企業，季度 3+ 職缺 |
| 成功定義 | 10–30 件驗證付費 hires、5–10 家重複下單客戶 |
| 收費模式 | 成功費 15–20% 首年薪，Day 30 驗證後開帳 |
