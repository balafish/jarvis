# Phase 1 Master Execution Plan

**Goal**: Build and validate a repeatable hiring-to-cash system in Vietnam (0–6 months).

## Success Criteria

- 10–30 verified paid hires
- 5–10 active employers with repeat behavior
- ≥45–55% gross margin trend
- Stable hire → verification → invoice → cash cycle
- Time-to-hire ≤ 35 days

## Team

| Role | Owns |
|------|------|
| Nam (Execution Lead) | Revenue generation (GTM, Product, Hiring conversion) |
| Kim | Delivery, financial control, risk (Ops, Verification, Collection) |
| Interns / Freshers | Sourcing, outreach, pipeline maintenance |

**Core rule**: If it affects getting the hire → Nam owns. If it affects getting the money → Kim owns.

## Discipline Rules

1. No sourcing without validated demand
2. No hire without Day 30 verification proof
3. No invoice without verification
4. No automation before system stability
5. Revenue protection > feature development
